# 🤖 Personal AI Gemini

Personal AI Chat GUI menggunakan:

- Python
- Flask
- Google Gemini API
- HTML
- CSS
- JavaScript
- Gunicorn

## Features

- Chat GUI
- Responsive mobile UI
- Gemini API
- Dark interface
- New Chat
- Clear Chat
- Typing indicator
- Health check
- Render deployment

## Environment Variables

Required:

GEMINI_API_KEY

Optional:

GEMINI_MODEL

Example:

GEMINI_MODEL=gemini-3.6-flash
